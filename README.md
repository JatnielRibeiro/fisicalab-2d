# UniversoLab

**Aprender, experimentar e descobrir.**

O **UniversoLab** é uma plataforma educacional multidisciplinar em desenvolvimento. Reúne laboratórios virtuais, simulações, conteúdos e desafios para apoiar o ensino e a aprendizagem por meio da experimentação.

## Áreas de conhecimento

- [Matemática](https://jatnielribeiro.github.io/universolab/matematica.html) — raciocínio, modelagem, geometria, álgebra e vetores.
- [Física](https://jatnielribeiro.github.io/universolab/fisica.html) — movimento, forças, equilíbrio, energia e interações.
- [Ciências](https://jatnielribeiro.github.io/universolab/ciencias.html) — matéria, vida, ambiente, Terra e Universo.

## Laboratórios disponíveis

- Lançamento Oblíquo
- Movimento Retilíneo
- Leis de Newton
- Estática e Torque
- Energia Mecânica
- Gravitação
- Movimento Circular
- Eletromagnetismo
- Vetores

## Identidade visual

- Títulos: Fredoka
- Textos e interface: Nunito
- Paleta: azul espacial, verde laboratório, azul ciência, roxo conhecimento, laranja descoberta e fundos claros.
- Fórmulas e expressões matemáticas: LaTeX renderizado pelo MathJax.

## Desenvolvimento e testes

O projeto utiliza HTML, CSS e JavaScript. O fluxo de GitHub Actions executa verificações de estrutura, recursos locais, links, sintaxe dos scripts e presença das configurações dos laboratórios a cada atualização da branch principal.

Para executar a verificação localmente com Node.js:

```bash
node scripts/smoke-test.mjs
```
