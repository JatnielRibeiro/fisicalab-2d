# UniversoLab

**Aprender, experimentar e descobrir.**

O UniversoLab é uma plataforma educacional em desenvolvimento que reúne experiências interativas, laboratórios virtuais, simulações, conteúdos e desafios de Matemática, Física e Ciências.

## Áreas de conhecimento

- Matemática
- Física
- Ciências

## Proposta

Transformar conceitos em experiências de aprendizagem por meio de simulações, visualizações, investigação e atividades interativas.

## Status

O projeto está em desenvolvimento. Sugestões, relatos de problemas e contribuições são bem-vindos por meio das [Issues do GitHub](https://github.com/JatnielRibeiro/universolab/issues).
